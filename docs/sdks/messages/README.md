# Messages

## Overview

### Available Operations

* [list](#list) - List all messages
* [create](#create) - Send a message to a partner

## list

Retrieve a paginated list of direct messages between your partner program and its partners, newest first.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="listMessages" method="get" path="/messages" -->
```typescript
import { Dub } from "dub";

const dub = new Dub({
  token: "DUB_API_KEY",
});

async function run() {
  const result = await dub.messages.list();

  console.log(result);
}

run();
```

## create

Send a direct message from your partner program to a partner. Until the partner replies, you can only send one message to a partner who isn't enrolled in your program. Sending a message marks the partner's unread messages to your program as read. You can send up to 10 messages a minute to the same partner.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="createMessage" method="post" path="/messages" -->
```typescript
import { Dub } from "dub";

const dub = new Dub({
  token: "DUB_API_KEY",
});

async function run() {
  const result = await dub.messages.create();

  console.log(result);
}

run();
```
